## Suggested GitHub Pages setup

1. Create a new PUBLIC GitHub repository named `flightfolio-site`.
2. Upload these four files to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will publish a URL similar to:
   `https://pierrecharlesheppell.github.io/flightfolio-site/`

Use:
- Marketing URL: `https://pierrecharlesheppell.github.io/flightfolio-site/`
- Support URL: `https://pierrecharlesheppell.github.io/flightfolio-site/support.html`

Do not enter the URLs into App Store Connect until GitHub Pages shows the site as published.
